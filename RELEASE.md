# Changelog

filter-sam3-detector release notes

## v0.1.0

### Added
- Initial release of SAM3 Detector filter
- Support for SAM2.1 Hiera models (tiny, small, base_plus, large)
- Text-based object detection using Grounding DINO
- Configurable detection parameters (confidence threshold, mask threshold, max detections)
- Frame visualization with bounding boxes and masks
- Multi-device support (CUDA, CPU, MPS)
- Docker and docker-compose support for pipeline deployment
- Comprehensive test suite
